# BranchOps Intake OS Product Spec

## MVP Scope

BranchOps Intake OS starts as a website-integrated module inside `odb-holdings-site`.

Included now:

- Structured contact form
- Cloudflare Worker API
- Cloudflare D1 storage
- AI classification adapter with rule-based fallback
- Admin lead dashboard
- CSV export
- Airtable and Notion mapping stubs

Not included yet:

- Billing
- User accounts
- File uploads
- Standalone SaaS repo
- White-label tenant configuration

## Future Extraction

When the internal version proves reusable, extract the module into `branchops-intake-os` with tenant settings, billing, user roles, CRM sync jobs, and packaged SOPs.

## Revenue Layers

- Internal Branch Off Holdings lead capture
- Client implementation setup fees
- Monthly SaaS subscription
- White-label licensing
- Consulting upsell for CRM and workflow automation
